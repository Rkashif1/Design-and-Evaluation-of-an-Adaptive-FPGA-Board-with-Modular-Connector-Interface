Design and Evaluation of an Adaptive FPGA Board with Modular Connector Interface

This repository contains the complete project files for the development of an adaptive FPGA board designed to interface with various sensor and actuator peripherals through dual high-density connectors. The FPGA module is implemented using the Xilinx Spartan-7 XC7S25 and follows a modular architecture that allows it to be plugged into different motherboards for dynamic reconfiguration.

📁 Contents include:

KiCad schematic and PCB layout files

Reference datasheets and mechanical dimensioning

LaTeX report and documentation

3D board rendering and connector spacing validation

🛠️ Key tools used: KiCad, Xilinx Vivado, Git, LaTeX

📌 Developed as part of an academic project demonstrating real-world modular hardware design and reconfigurable embedded systems.
